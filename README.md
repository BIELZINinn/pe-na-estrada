# 🦜 Pé na Estrada — Missões CCB

App web (PWA) para quem viaja em missão: mapa do Brasil em estilo cartoon, viagens com várias paradas,
cultos da CCB por data, pontos de apoio na rota, lembretes, conquistas, mapas offline e backup no Google Drive.

Sem build: é só HTML/CSS/JS. Os dados ficam no aparelho (e, se você quiser, na sua pasta privada do Google Drive).
